PHISHING — OUTSMART THE TRICKSTERS

First, extract the provided Toolkit. Inside the Toolkit, locate the Detecting Phishing Mail ZIP file and extract it using the password provided by the Admin.

This round follows a challenge-unlocking mechanism. Initially, only the 1st challenge will be unlocked. When you open the first challenge, you will find an email image. Identify all the spelling mistakes and note down the correct words.

One of the corrected words will act as the unlocking key for the next challenge. Continue this process until all challenges are unlocked and completed.

For the CTF submission, submit the correct word that acts as the unlocking key for the next challenge as the flag for the current challenge in the War Room → CTF → Challenges category.

CHALLENGE STRUCTURE
  • Total Challenges20
  • Points per Challenge10
  • Maximum Points200
TOTAL: 200 POINTS

SQL INJECTION — DATABASE SECRETS

First, extract the provided Toolkit. Inside the Toolkit, locate the SQL Injection ZIP file and extract it using the password provided by the Admin.

The Admin will provide you with a target website for the challenge. Analyze the target application and perform the SQL Injection challenge in the provided environment. Through the database-leak process, identify the CTF flag hidden in the target application or database.

After identifying the flag, submit it in the War Room → CTF → Challenges category against the respective challenge.

CHALLENGE STRUCTURE
  • SQL Injection Challenge10
  • CTF Flag Identification10
  • Maximum Points10
